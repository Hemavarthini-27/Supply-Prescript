# SupplyPrescript

## Project Overview

SupplyPrescript is a Closed-Loop Prescriptive Analytics system for Supply Chain Management.

The system predicts shipment delays using Machine Learning and recommends the best business decision based on cost, delivery time, and operational constraints.

## Project Objectives

- Predict shipment delays
- Recommend optimal business actions
- Compare multiple logistics options
- Track business decisions
- Improve recommendations using feedback
